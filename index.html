TECNOLOGÍA

🤖 ¿Qué es la Robótica?

Es la ciencia encargada de diseñar, construir y dar vida a las máquinas (los robots). Un robot combina motores, sensores y circuitos para moverse e interactuar con el mundo físico.

💻 ¿Qué es la Programación?

Es el idioma que usamos para hablar con las máquinas. Es escribir instrucciones y pasos lógicos (llamados algoritmos) para enseñarle a la computadora o al robot qué hacer.

⚡ ¿Cómo se Relacionan?

¡Son un equipo perfecto! El robot es el cuerpo (hardware) y la programación es el cerebro (software). ¡Sin código, el robot no sabría cómo moverse!

🧩 LENGUAJES Y HERRAMIENTAS 🧩

TIPOS DE CÓDIGO

¿CÓMO LE HABLAMOS AL ROBOT?

🧩 Programación por Bloques (Scratch / MakeCode)

¿Qué es? Es como armar un rompecabezas visual. Encajas piezas de colores que ya tienen órdenes escritas.

🎯 ¿Para qué sirve? Ideal para empezar. Te enseña la lógica de programar sin preocuparte por cometer errores al escribir.

💻 Código en Texto (Arduino / C++)

¿Qué es? Es escribir comandos con letras, símbolos y palabras clave en el teclado.

🎯 ¿Para qué sirve? Para dar instrucciones muy precisas a placas como Arduino, controlando motores y luces al milisegundo.

🐍 Python e Inteligencia Artificial

¿Qué es? Un lenguaje de texto muy claro y fácil de leer, usado por profesionales de todo el mundo.

🎯 ¿Para qué sirve? Para robots avanzados que procesan visión por cámara, reconocen voz o toman decisiones complejas.

📊 VALORES DE PROGRAMACIÓN 📊

TIPOS DE DATOS

¿CÓMO GUARDA INFORMACIÓN EL ROBOT?

Las variables son como cajitas guardadas en el cerebro del robot. Cada cajita almacena un tipo de valor específico:

🔢 Entero (int)

¿Qué guarda? Números enteros positivos o negativos (sin decimales).

💡 Ej: int velocidad = 100;
int nivel = 5;

📐 Decimal (float / double)

¿Qué guarda? Números que contienen puntos decimales para mediciones precisas.

💡 Ej: float distancia = 12.5;
float temp = 24.8;

🔤 Texto (string / char)

¿Qué guarda? Palabras, letras o frases escritas siempre entre comillas.

💡 Ej: string nombre = "Robo";
char estado = 'A';

🔘 Booleano (bool)

¿Qué guarda? Solamente 2 valores posibles: Verdadero (true) o Falso (false).

💡 Ej: bool encendido = true;
bool chocando = false;
